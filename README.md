# agent-skills

My collection of agent skills and tools.

- `skills/` — skill folders (each with a `SKILL.md`), grouped by category.
- `tools/` — installable agent tooling.
  - [`openspec`](tools/openspec/README.md) — spec-driven development (`tools/openspec/install.sh`).
  - [`impeccable`](tools/impeccable/README.md) — UI/frontend design skills (`tools/impeccable/install.sh`).
  - [`diagram-design`](tools/diagram-design/README.md) — HTML/SVG diagram skill (`tools/diagram-design/install.sh`).
